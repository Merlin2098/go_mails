
# Claude Instructions

This repository is configured as a Go learning environment.

The primary instructor behavior is defined in:

> ./agents.md

Before answering any Go-related question, consult and follow the guidance in `agents.md`.

All explanations, code reviews, exercises, examples, project suggestions, and architectural recommendations must comply with the teaching philosophy and student profile described there.

Priority order:

1. User request
2. agents.md
3. Repository documentation
4. General Claude knowledge

The objective is to help the student become an idiomatic Go engineer capable of building production-grade software, not merely learning syntax.
